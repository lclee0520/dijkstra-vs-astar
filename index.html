항목DijkstraA*

      
우선순위g(n): 출발점부터 실제 비용g(n) + h(n): 실제 비용 + 남은 거리 추정치

      
시간 (이진 힙, 최악)O((V + E) log V)O((V + E) log V)

      
공간O(V): g, parent, 우선순위 큐O(V): 같음 + h 값

      
실제로 꺼내는 정점출발점에서 목표 거리보다 가까운 정점 전부h가 정확할수록 목표 방향 정점만

      
최단 경로 보장음수 간선이 없으면 보장h가 실제 남은 거리를 넘지 않으면 보장

      
관계h(n) = 0으로 두면 A*는 Dijkstra와 똑같이 동작한다.

    

    
두 알고리즘 모두 정점을 우선순위 큐에서 한 번씩 꺼내고(V번, 각 O(log V)), 간선마다 한 번씩 거리 갱신을 시도한다(E번, 각 O(log V)). 그래서 최악 복잡도는 같다. 차이는 실제로 몇 개를 꺼내느냐이다. Dijkstra는 목표 방향을 모르므로 출발점 기준 동심원으로 넓혀 가고, A*는 h 덕분에 목표에서 먼 정점을 큐 뒤로 미룬다.
